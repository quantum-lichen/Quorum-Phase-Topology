# Standards de Contribution "Protocole Ouellette"

Nous accueillons les contributions qui respectent la rigueur scientifique suivante :

1. **Rigueur Mathématique** : Toute modification des modèles doit inclure une analyse dimensionnelle complète et une validation de stabilité (Lyapunov).
2. **Standard LaTeX** : Utilisez exclusivement LaTeX pour les équations.
3. **Éthique de Recherche** : Les simulations doivent être reproductibles. Les paramètres de bruit de Poisson et les constantes de raideur $k$ doivent être documentés.
4. **Pull Requests** : Chaque PR doit lier une prédiction théorique à un test expérimental (ou simulation ABPs) potentiel.
